# 4 Axes Dev/Tech Test

Um teste interativo que descobre seu perfil como desenvolvedor através de 4 eixos principais de trade-offs.

Responda 20 perguntas em escala Likert (1 a 5) e receba um score 0-100 para cada eixo:
- Entrega vs Qualidade
- Produto vs Infra
- Generalista vs Especialista
- Solo vs Liderança

O resultado inclui um gráfico radar, interpretações personalizadas e recomendações práticas. Sem dependências externas, roda direto no navegador abrindo o arquivo HTML.
